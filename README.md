An open-source collection of cybersecurity study notes covering Linux, networking, security fundamentals, Nmap, and penetration testing.

Technical explanations, command examples, and reference material for students and hands-on learners.

🌐 **[Website](https://radz-04.github.io/Cybersecurity-survival-notes/)**

💬 **[Discussions](https://github.com/Radz-04/Cybersecurity-survival-notes/discussions)**

### 📁 [Linux](./Linux/)

*  **[Architecture.md](./Linux/Architecture.md):** Filesystem hierarchy and Linux system architecture.
*  **[Permissions.md](./Linux/Permissions.md):** File permissions, chmod, chown, SUID, SGID, Sticky Bit and umask.
*  **[Cheatsheet.md](./Linux/Cheatsheet.md):** Process management, systemd services, and system commands.
*  **[Networking.md](./Linux/Networking.md):** iproute2 suite, DNS configuration, SSH hardening,fail2ban, TCP Wrappers and UFW.

### 📁 [Cybersecurity-fundamentals](./Cybersecurity-fundamentals/) 
*  **[CIA_triad.md](./Cybersecurity-fundamentals/CIA_triad.md)**: Cybersecurity Fundamentals

### 📁 [Tools](./Tools/) 
*  **[Nmap.md](./Tools/Nmap.md):** Network discovery, port scanning, service/OS detection, NSE scripting, and firewall/IDS evasion techniques.

### 📁 [Networking](./Networking/)

*  **[Basics.md](./Networking/Basics.md):** Networking fundamentals, LANs, WANs, VPNs, OSI, TCP/IP, and encapsulation.
*  **[Components.md](./Networking/Components.md):** Hosts, interfaces, network devices, firewalls, and servers.
*  **[Transmission.md](./Networking/Transmission.md):** Signals, transmission media, and duplex modes.
*  **[Protocols.md](./Networking/Protocols.md):** Common protocols, service ports, and how they work together.
*  **[DHCP.md](./Networking/DHCP.md):** Automatic IP configuration, DORA process, DHCP leases, and relay agents.
* **[Communication.md](./Networking/Communication.md):** MAC and IP addressing, ports, ARP, and communication across networks.

### 📁 [Penetration Testing](./Penetration-Testing/)
* **[Information Gathering](./Penetration-Testing/Information-Gathering.md):** Reconnaissance methodology, OSINT, DNS enumeration, subdomain discovery, web fingerprinting, and network scanning.


## About the Project

Cybersecurity Survival Notes is an open-source project created and maintained by [Radzivon Ferrigni Dioguardi](https://github.com/Radz-04).

I regularly update the repository as I continue studying cybersecurity, adding new material, improving existing explanations, and correcting mistakes.
